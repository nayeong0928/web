# 클래스 추상화하기

- ListProductRepository, DatabaseProductRepository 가 productRepository에 의존하도록 변경.
- 의존성 주입을 통해 테스트/서비스 환경에 맞는 productRepository를 사용하도록 한다.

### 테스트 환경

- ListProductRepository
  ```java
  @Repository
  @Profile("test")
  public class ListProductRepository implements ProductRepository {
  ```
- application-test.properties
  ```bash
  spring.application.name=demo
  spring.autoconfigure.exclude=org.springframework.boot.jdbc.autoconfigure.DataSourceAutoConfiguration
  ```

### 서비스 환경

- DatabaseProductRepository.class

  ```java
  @Repository
  @Profile("prod")
  public class DatabaseProductRepository implements ProductRepository {
  ```

- application-prod.properties
  ```bash
  spring.application.name=demo
  spring.datasource.url=jdbc:mysql://localhost:3307/product_management
  spring.datasource.username=root
  spring.datasource.password=hanbig
  spring.datasource.driver-class-name:com.mysql.cj.jdbc.Driver
  ```
