# MySQL 도커 세팅

```bash
docker run --name some-mysql ^
-p 3307:3306 ^
-e MYSQL_ROOT_PASSWORD=hanbig ^
-d mysql:8.0.29 ^
--character-set-server=utf8mb4 ^
--collation-server=utf8mb4_general_ci
```

### mysql 접속

```bash
mysql -u root -p
```

### 테이블 생성

```bash
CREATE TABLE products (
	id BIGINT PRIMARY KEY NOT NULL AUTO_INCREMENT,
	name VARCHAR(100) NOT NULL,
	price INT NOT NULL,
	amount INT NOT NULL
);
```

### 더미 데이터 생성

```bash
INSERT INTO products (name, price, amount) values ('product1', 100, 10);
INSERT INTO products (name, price, amount) values ('product2', 300, 25);
INSERT INTO products (name, price, amount) values ('product3', 500, 70);
```

# 애플리케이션에서 DB 연결 세팅

## 커넥션 풀 초기화

```java
    @Bean
    public ApplicationRunner runner(DataSource dataSource){
        return args -> {
            Connection connection=dataSource.getConnection();
        };
    }
```

- 커넥션: 애플리케이션과 데이터베이스 사이의 연결.
- 커넥션풀: 애플리케이션이 앞으로 사용할 커넥션들을 미리 만들어두고 애플리케이션에서 커넥션이 필요한 곳에 커넥션을 빌려준다.
- ApplicationRunner로 커넥션 풀을 초기화해주는 이유: 커넥션 풀이 처음 사용되는 시점에 생성되기 때문. 이를 초기화해주지 않으면 애플리케이션 시작 이후 처음 받는 요청 때 커넥션 풀이 생성되는 시간만큼 지연이 발생한다.
