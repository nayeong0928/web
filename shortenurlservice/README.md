# 단축 URL 생성 서비스 개발

## 요구사항

- bitly 와 같은 단축 URL 서비스를 만들어야 한다.
- 단축된 URL의 key는 8글자로 생성되어야 한다.
- 사용자가 단축된 URL로 요청하면 원래의 URL로 리다이렉트되어야 한다.
- 원래의 URL로 다시 단축 URL을 생성해도 항상 새로운 단축 URL이 생성되어야 한다. 이 때, 기존에 생성했던 단축 URL도 여전히 동작해야 한다.
- 단축된 URL -> 원본 URL로 리다이렉트될 때마다 카운트가 증가해야 하고, 해당 정보를 확인할 수 있는 API가 있어야 한다.
- 데이터베이스 없이 컬렉션을 활용해서 데이터를 작성한다.
- 기능이 정상 작동하는 것을 확인할 수 있는 적절한 테스트코드가 있어야 한다.
- 해당 서비스를 사용할 수 있는 UI 페이지가 있어야 한다.
